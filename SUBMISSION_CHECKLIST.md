# Submission Checklist

- [ ] Open the prototype locally and review every screen.
- [ ] Deploy using Netlify Drop or GitHub Pages.
- [ ] Open the deployed link in an incognito window.
- [ ] Record a 5–6 minute walkthrough.
- [ ] Keep the walkthrough natural; explain decisions rather than reading slides.
- [ ] Review the product decisions note and make sure you can explain every trade-off.
- [ ] Confirm the PPT and document open correctly.
- [ ] Submit the live link, hosting URL, video link, PPT and one-page note.
- [ ] Be transparent that the current prototype uses synthetic data and calculation-based demo prompts.
